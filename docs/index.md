# Rusk β 03

Rusk は競技プログラミング向けの言語です。作者自身にとっての書きやすさと、競技プログラミングで十分な実行速度を重視して開発しています。

このドキュメントは第3段階の `rusk_b_03` を対象とします。完成した [rusk_b_02](https://github.com/shogo314/rusk_b_02) の実装・設計・テストを出発点に開発を続けます。β03の追加機能と完成条件はこれから決めるため、開始時点の言語仕様はβ02と同じです。

!!! note "開発状況"
    C++20 を生成するプロトタイプです。基本型の入出力、整数演算、共有・コピー・代入、短絡論理演算、条件分岐、while / for、再帰とオーバーロードが使えます。多次元配列、ソート・二分探索、ASCII 文字列操作にも対応します。構造体、タプルと分解、型引数付きの関数・構造体、`include` によるライブラリ分割も使えます。高度なジェネリクスや実行速度の最適化は今後の課題です。
